# 受験日程カレンダー MVP

中学受験家庭の情報収集負担を減らす、モバイル優先の静的PWAです。7校と主要模試4社の公式情報をGit管理し、確認済み日程だけを横断表示してRFC 5545 ICSとして書き出します。ログイン、サーバー、個人情報保存、有料サービス、実行時LLMはありません。

## 利用者向けUI

- 学校と模試を別々に選択できます。
- 選んだ学校・模試の予定だけを時系列表示します。
- 各予定をカレンダー操作の対象にするか個別に選べます。
- 追加用ICSと取消用ICSを作成できます。
- 申込受付開始が公式確認できた予定は、試験日と別の予定として表示します。
- 選択内容はブラウザの `localStorage` だけに保存します。

試験版は検索エンジンへ掲載せず、アクセスキーを含む共有URLを知る利用者だけが開けます。一度開いた端末では許可状態を端末内に保存するため、ホーム画面へ追加したPWAからも利用できます。これはログインを使わない簡易的な共有制限であり、厳密な本人確認ではありません。

## ローカル開発

Node.js 22以上を使用します。

```bash
npm ci
npm run dev
```

品質確認は `npm run check`、375pxの実ブラウザ確認は初回に `npx playwright install chromium` を実行してから `npm run test:e2e` です。

## データの追加と監査

GitHub上の公開正本は `data/schools.json`、`data/events.json`、`data/change-history.json`、イベント仕様は `data/event.schema.json` です。監査前の候補・インシデント・個別カレンダー連携状態は非公開の運営ストアに置き、公開リポジトリへ入れません。

1. School Data Agentが一次情報を確認し、非公開の運営ストアへ必須メタデータを持つ `candidate` を追加する。
2. Data Auditor Agentが元情報、年度、日時、対象学年、申込期間、重複、矛盾を独立確認する。
3. 確認完了時だけ `status: verified` と `verified_at` を設定し、`data/events.json` へ反映する。
4. `npm run generate:data` を実行する。
5. `npm run check` を通す。

生成処理は `verified` かつ `verified_at` のあるイベントだけを `public/data/events.json` へ出力します。候補・隔離データは公開成果物に入りません。

## カレンダー連携

画面の「Googleカレンダーへ追加」で追加用 `.ics`、「Googleカレンダーから削除」で同じ予定IDを持つ取消用 `.ics` を保存します。ファイルを開いてカレンダー側で確定してください。カレンダーアプリによっては取消用ファイルの読込み時に削除確認が表示されます。直接OAuth連携は行いません。

## ゼロコスト公開

`npm run build` の `dist/` は静的ファイルだけです。mainブランチの更新時にGitHub Pagesへ無料で自動配置します。検索除外は `robots.txt` と `noindex` の両方で指定しています。

## LINE運営通知

セットアップと安全設計は [docs/line-setup.md](docs/line-setup.md) を参照してください。GitHub Issueを監査可能な記録として残し、指定プレフィックスの重要通知だけをLINE Messaging APIへ転送します。

## 既知の制約

- 学校の確認済み公開日程は現在6件です。監査済みの学校情報が増えると自動的に選択肢へ反映できます。
- 主要模試4社について、実施日21件と公式確認できた申込受付開始7件を掲載しています。
- ICSは一方向のスナップショットです。更新時は再インポートが必要です。
- 取消用ICSの処理方法はカレンダーアプリにより異なります。確実なワンタップ削除にはGoogle OAuthが必要です。
- ブラウザ通知、ログイン、Google Calendar API、全国展開はMVPに含みません。
